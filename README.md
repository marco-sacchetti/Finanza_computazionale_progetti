# 📈 Finanza Computazionale - Progetti

Repository dedicato all'implementazione pratica di modelli di **Finanza Computazionale**, **Quantitative Finance** e **Gestione del Portafoglio** sviluppati in Python.

## 📁 Indice dei Progetti

| Progetto / Modulo | Descrizione | Stato |
| :--- | :--- | :---: |
| 📊 [**Markowitz**](./Markowitz) | Ottimizzazione di portafoglio (Frontiera Efficiente, CAL, Portafoglio di Sharpe) e Modello Multi-Fattoriale (S&P 500 & Brent). |  Completato |
| 🛡️ [**calcolo_VaR**](./calcolo_VaR) | Calcolo del Value at Risk (VaR) e Expected Shortfall (Parametrico, Storico e Monte Carlo). | 🏗️ In arrivo |

## 🛠️ Tecnologie e Librerie Utilize

I progetti sono realizzati in **Python** e utilizzano le principali librerie scientifiche e finanziarie:

* **Analisi dati & Calcolo numerico:** `pandas`, `numpy`
* **Modellizzazione statistica:** `statsmodels`, `scipy`
* **Visualizzazione dati:** `matplotlib`, `seaborn`
* **Data Retrieval:** `yfinance`
